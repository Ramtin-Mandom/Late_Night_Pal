Write one document with role checklist. Group items under short topic headings. When several files contribute, identify their exact source labels at the relevant headings.

Use itemize lists (a box such as $\square$ as the item label works well). Start each item with an observable action verb such as derive, interpret, calculate, distinguish, sketch, or justify. Name a specific object and, where useful, the condition for success. For example, turn “Understand the graph” into “Use the intercept to estimate the starting value and state its units.” Use that pattern only with material from the sources.

Cover the main learning objectives. Keep each item small enough for a student to check after one attempt. Include both explanation and application where the sources teach both. Leave answers in the notes or answer key.
