Write one document with role checklist: a clear, motivating self-check list.

Start with one short paragraph, without a heading, saying what a student who ticks every item can do. Then give each topic a numbered \section, naming the file and citing its pages with \src in a short opening sentence when several files contribute.

Use the checklist environment for every list of items (\begin{checklist} \item ... \end{checklist}). Start each item with an observable action verb such as derive, prove, interpret, calculate, distinguish, sketch, or justify. Name a specific object and, where useful, the condition for success. For example, turn "Understand ideals" into "Prove that \(\langle r\rangle = R\) exactly when \(r\) is a unit." Use that pattern only with material from the sources.

Cover the main learning objectives, including every definition, theorem and method the sources teach. Keep each item small enough for a student to check after one attempt, and include both explanation and application where the sources teach both. Where a topic has a classic trap, add a short pitfall callout after its list. Finish with a summarybox naming the two or three items that matter most. Leave answers in the notes or answer key.
