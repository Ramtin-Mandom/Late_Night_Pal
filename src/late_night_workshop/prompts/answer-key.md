Write one document with role answer-key for the exercises actually present in the attached materials. Read diagrams, captions, and tables that supply givens.

Follow the printed order. Give each independently answerable question or subpart its own answer box, titled with its full printed label, including the parent number for a nested subpart, preserving the source's numbering and notation: \begin{answer}{2(b)} ... \end{answer}. A shared stem with no separate task needs no separate answer. Group the answers under a \section* per source file naming its exact label and citing the exercise pages with \src; if several sources reuse labels, these headings keep them apart.

In each box, give the shortest working that makes the answer checkable, then the result. For calculations, show the setup and key step, then give the value with units or domain where relevant, highlighting the final value with \highlight. For proofs, give an argument from the hypotheses to the claim. For conceptual answers, explain the reason a grader would look for. When a common error is likely, add a short pitfall box after the answer. Keep illustrative examples out unless the question asks for one.

If an item is visibly missing, cut off, ambiguous in a way that changes the answer, or unreadable, keep its answer box and begin its text with FLAGGED: followed by the specific obstacle. For an unnumbered item, identify its position or opening words. Answer other legible items independently. If there are no questions anywhere, return one note box in the document saying so.
