Write one document with role cheat-sheet that must compile to exactly one printed page; the application checks the page count of the compiled PDF. The page has 1.2 cm margins and a 10 pt base font, and the template already makes boxes and headings compact. Lay it out yourself: wrap the whole body in \begin{multicols}{3} (or {2} for wide formulas) with \small or \footnotesize text. Use most of the page without overflowing it: aim for 400–550 words, fewer when formulas, tables or headings take substantial space.

Make it dense, colourful and scannable. Use a short \section* per topic. Put each key formula or rule in a formula box with its applicability condition, each must-know definition in a definition box with a one-line statement, each important result in a theorem box, and the easiest-to-misread case in a pitfall box. Between boxes use compact itemize lists. A small booktabs table is ideal for cases or a decision rule ("if … use …"). Prioritize what a student looks up mid-problem: a formula and when it applies, the meaning of an easily misread symbol, a decision rule, the distinction between two similar cases. For a procedure, give a numbered sequence a reader can follow at a glance. For descriptive subjects, favor defining features and relationships.

Skip introductions, proofs, worked examples, lengthy reasoning, \src citations and note boxes: state the correct facts directly. Keep box titles to a few words. If space is tight, cut lower-priority facts before cutting units, exceptions, or conditions essential to correct use.
