LaTeX packages installed for math and science notes
====================================================

Installed on 2026-11-07 on the development machine (Windows 10, MiKTeX 25.12,
user install at %LOCALAPPDATA%\Programs\MiKTeX), with
    miktex packages install --package-id-file=<list>
from the default MiKTeX package repository. 89 packages were installed (no extra
dependencies were pulled in). Installed packages went from 230 to 319.

Important for Late Night Pal
  - The app's templates (templates/document.tex, templates/cheat-sheet.tex) only use
    fontspec, geometry, enumitem, parskip and multicol. Gemini's output is escaped
    plain text, so the generated PDFs do not use these packages, and they look exactly
    as before. The packages only matter if a template is changed to load them.
  - Another PC does not get these from the ZIP. Install them there with the command
    at the end of this file.

Verified
  - One lualatex test document loading all of the packages below (except nicematrix)
    compiled, with physics/braket/cancel/mathrsfs/dsfont math, siunitx units, mhchem
    and chemformula reactions, a chemfig molecule, a pgfplots plot, tikz-cd,
    circuitikz, tcolorbox and booktabs.
  - The app's own templates still compile (renderer edge-case check).

Known limitations
  - nicematrix 7.12 is installed but does not load: it needs LaTeX 2026-06-01 and this
    MiKTeX has LaTeX2e 2025-11-01. A full MiKTeX update (MiKTeX Console > Updates, or
    "miktex packages update") would fix it but also changes the LaTeX setup the demo
    was verified on. Not done.
  - physics and siunitx both define \qty. If you load both, use \SI{...}{...} for units.
  - lm-math, stix2-otf, xits, tex-gyre-math, firamath and libertinus-fonts are OpenType
    maths fonts for unicode-math (\setmathfont{Latin Modern Math} etc.). The font index
    was refreshed with "luaotfload-tool --update" after installing.
